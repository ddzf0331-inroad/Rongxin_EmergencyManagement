# 有毒有害物质泄漏事故模拟计算说明

## 1. 文档用途

本文档说明事故模拟页面中各项参数的含义、参数对计算结果的影响、不同泄漏类型的计算过程，以及 ERPG 事故后果分区的解读方法。

本功能用于平坦地形下的快速事故后果评估，为人员疏散、警戒区划定和应急救援提供辅助依据。结果不等同于 CFD 计算，也不代替有资质人员的专业评估。

## 2. 使用前提

运行模拟前必须满足以下条件：

1. 已完成 2.5D 地图标定，独立校验点最大误差不超过 5 m。
2. ERPG 阈值以及非内置液化气的物性已由具备专业能力的人员核对。
3. 风速不低于 0.5 m/s，并已确认 Pasquill 稳定度。
4. 设备压力使用绝对压力，不是表压。
5. 各项输入使用页面标明的 SI 单位。
6. 地图上已点选正确的泄漏位置，并出现红色小三角泄漏点标识。

## 3. 公共场景参数

### 3.1 事故物质

事故物质决定分子量、气液密度、沸点、汽化热、热容、绝热指数和 ERPG 阈值等基础数据。

主要影响：

- 气体密度和分子量影响高斯模型或 SLAB 重气模型的选择。
- 液体热容、沸点和汽化热影响闪蒸比例。
- 分子量、环境温度和压力影响 ppm 与 kg/m³ 的换算。
- ERPG-1、ERPG-2、ERPG-3 阈值直接决定蓝、黄、红三级影响区。

系统按 CAS 自动为氨、硫化氢、氯气、二氧化硫加载固定工程物性。其他气体按非冷凝理想气体近似，绝热指数统一取 `1.4`，气体密度和气相热容根据分子量及计算工况推导；结果摘要会显示“近似物性·理想气体”。

分子量由第三方接口以 `g/mol` 提供，系统在接口边界换算为 `kg/mol`。ERPG-1、ERPG-2、ERPG-3 必须完整且满足递增关系；物性与 ERPG 的来源、版本可不填写。非内置液化气仍必须提供真实液体物性。

### 3.2 库存量（kg）

库存量是设备中当前可能释放的物料总质量。

主要影响：

- 对连续泄漏，库存量主要限制能够持续泄漏多长时间。
- 对瞬时完全释放，库存量就是一次性进入烟团的总质量。
- 库存量越大，影响区通常越大、持续时间越长。

### 3.3 物料温度（K）

物料温度是泄漏发生前物料在设备内的温度。

主要影响：

- 加压气体的孔口质量流率与温度有关。
- 液化气温度高于常压沸点越多，闪蒸比例通常越大。
- 温度必须使用 K。摄氏度换算为 `K = ℃ + 273.15`。

### 3.4 释放高度（m）

释放高度是泄漏口相对地面的高度。

主要影响：

- 贴地释放更容易在泄漏点附近形成较高的地面浓度。
- 高位释放的气团需要在下风向扩散后才逐渐影响地面。
- 本系统不计算厂房、储罐和管廊对高位羽流的绕流影响。

### 3.5 泄漏点坐标

泄漏点使用厂区平面坐标：

- X 向东，单位 m。
- Y 向北，单位 m。

点击 2.5D 地图时，系统根据标定矩阵将图片位置反算为平面坐标，并在地图上显示红色小三角；三角尖端就是实际泄漏坐标。泄漏点位置决定整个影响区的起点，点位选错会使全部后果分区整体偏移。

## 4. 泄漏类型一：加压气体孔泄漏

### 4.1 适用情况

适用于设备、储罐或管道内已经是气相的有毒物质，通过裂口或圆形等效孔口向大气泄漏。

不适用于液化气喷出后发生闪蒸的情况，该情况应选择“液化气闪蒸/液池”。

### 4.2 专用参数

#### 隔离时间（s）

从泄漏发生到阀门关闭、联锁切断或设备停机后有效停止供料的时间。

有效泄漏时间取以下三者的最小值：

`min(库存耗尽时间, 隔离时间, 3600 s)`

隔离时间越短，总释放量和持续时间通常越小。当库存已经提前耗尽时，继续增大隔离时间不会增加释放量。

#### 孔径（m）

孔径是圆形等效泄漏孔的直径。系统按以下关系计算孔口面积：

`A = πd² / 4`

因为面积与孔径的平方成正比，孔径增大一倍时，其他条件不变的理想情况下孔口面积增大为四倍，质量流率也会大幅增加。

#### 设备绝压（Pa）

设备内部的绝对压力。输入前必须将表压换算为绝压：

`绝压 ≈ 表压 + 当地大气压`

设备压力越高，孔口泄漏流率通常越大。系统会根据设备压力与环境压力的比值，自动判断是否达到临界流动（声速/阻塞流），并采用对应孔口流量公式。

#### 流量系数

当前页面默认流量系数 `Cd = 0.62`。它用于表示实际孔口收缩、摩擦与理想流动之间的差异。实际破口形状明显不同时，应由专业人员核对取值。

### 4.3 计算过程

1. 根据孔径计算孔口面积。
2. 根据设备压力、环境压力、物料温度、绝热指数和分子量判断阻塞流或亚声速流。
3. 计算质量泄漏速率 kg/s。
4. 根据库存、隔离时间和 60 min 上限计算有效泄漏时间。
5. 计算进入大气的总质量。
6. 进入高斯或 SLAB 扩散模型。

## 5. 泄漏类型二：液化气闪蒸/液池

### 5.1 适用情况

适用于液氨等加压液化气体通过破口泄漏。液体离开设备后，一部分立即闪蒸成气体，其余部分可形成液池，再通过地面传热和质量传递继续蒸发。

### 5.2 共用的孔口参数

隔离时间、孔径和设备绝压的含义与加压气体相同，但液相流出速率按液体孔口流动计算：

`m_liquid = Cd × A × sqrt(2 × ρ_liquid × (设备绝压 - 环境压))`

当设备压力不高于环境压力时，该液相压差泄漏场景不成立，系统会阻止计算。

### 5.3 闪蒸计算

系统使用液体热容、物料温度、常压沸点和汽化热计算闪蒸比例：

`F_flash = Cp_liquid × (T_release - T_boiling) / 汽化热`

计算值限制在 0～1 之间。

主要影响：

- 物料温度越高，闪蒸比例通常越高。
- 沸点越低，在同一释放温度下闪蒸倾向越明显。
- 汽化热越大，将同等质量液体变为蒸气所需能量越多，闪蒸比例越低。

### 5.4 液池面积（m²）

液池在地面上的有效蒸发面积。

- 面积越大，与地面和空气接触的范围越大，蒸发速率通常越大。
- 应优先使用防火堤、围堰或排液区的实际受限面积。
- 不能简单使用整个装置区面积代替液池面积。

### 5.5 地面热通量（W/m²）

地面和周边环境向液池提供的有效热通量。热量蒸发速率按以下关系计算：

`m_heat = 地面热通量 × 液池面积 / 汽化热`

地面热通量越大，由传热引起的蒸发速率越大。该值与地面材料、温度、日照和液池存在时间有关。

### 5.6 质量传递系数（m/s）

质量传递系数表示蒸气从液池表面进入空气的传质能力。质量蒸发速率按以下关系计算：

`m_mass = 质量传递系数 × 液池面积 × 饱和蒸气密度`

取值越大，质量蒸发速率越大。该参数应来自现场技术资料、实验数据或经认可的工程关联式。

### 5.7 蒸气压（Pa）

蒸气压用于计算液池表面的饱和蒸气密度。内置四种物质由系统自动加载固定参考值，页面不再重复要求输入；非内置液化气在化学品资料中维护。

- 蒸气压越高，物料越容易蒸发。
- 当前内置值为固定工程参考值，不随物料温度自动修正，因此温度偏离参考条件时不确定性会增大。

### 5.8 总蒸气源强

液化气场景的有效气相源强由两部分组成：

`总气相源强 = 闪蒸速率 + 液池蒸发速率`

液池蒸发量不会超过扣除闪蒸后的剩余液体供给量。

## 6. 泄漏类型三：瞬时完全释放

### 6.1 适用情况

适用于很短时间内几乎全部释放的场景，例如小型容器突然完全失效。

不应将持续数分钟或数十分钟的孔泄漏设为瞬时释放。

### 6.2 参数和计算特点

瞬时场景使用：

- 库存量：一次性进入烟团的总质量。
- 物料温度：初始释放温度。
- 释放高度：烟团初始中心高度。
- 泄漏点坐标：烟团初始位置。

该场景不使用孔径、设备压力和隔离时间。系统将全部库存作为瞬时烟团质量，随风移动并逐渐扩散。

与连续烟羽不同，瞬时烟团对某个固定位置的影响通常是“到达—达到峰值—离开”，因此应重点查看到达时间和逐时羽流。

## 7. 气象参数

### 7.1 风速（m/s）

风速决定气体的输送速度和稀释强度。

- 风速增大时，羽流到达下风向的时间缩短。
- 在其他条件不变时，风速增大通常会降低同一位置的浓度，但不代表影响距离必然按同一比例减小。
- 风速低于 0.5 m/s 时，当前快速模型不适用，系统会要求人工修正或确认。

### 7.2 风向（来向，°）

风向按气象定义表示“风从哪里来”：

- 0°：北风，气体向南扩散。
- 90°：东风，气体向西扩散。
- 180°：南风，气体向北扩散。
- 270°：西风，气体向东扩散。

系统将风向加 180° 后作为羽流下风向。风向输入错误会使影响区整体朝错误方向旋转。

### 7.3 环境温度（K）

用于计算空气密度、重气判定和 ppm 与质量浓度的换算，同时作为 SLAB 气象输入。

### 7.4 环境压力（Pa）

用于设备内外压差、空气密度和 ppm 换算。环境压力不能直接使用海平面标准压力代替高海拔现场实测值。

### 7.5 相对湿度（%）

相对湿度作为 SLAB 重气模型的气象输入并记录在计算快照中。当前高斯计算中，相对湿度不直接修改 Pasquill-Gifford 扩散系数。

### 7.6 地表粗糙度（m）

用于表示地面建筑、灌木、设备等对近地风场和湍流的综合影响。

- 影响摩擦速度和 Richardson 数，因此可能影响高斯/SLAB 模型路由。
- 在高斯模型中用于对水平和垂直扩散尺度进行小幅修正。
- 该参数不等同于单个建筑物的高度。

### 7.7 Pasquill 稳定度

Pasquill 稳定度从 A 到 F 表示大气湍流和垂直混合能力：

| 类别 | 大气状态 | 典型扩散特征 |
| --- | --- | --- |
| A | 强不稳定 | 混合强，羽流宽，浓度衰减快 |
| B | 不稳定 | 扩散较强 |
| C | 弱不稳定 | 扩散中等偏强 |
| D | 中性 | 常用的中性条件 |
| E | 弱稳定 | 羽流较窄，稀释较慢 |
| F | 稳定 | 垂直混合弱，可形成较长的高浓度羽流 |

稳定度不得留空。不能确定时，应由专业人员结合日照、云量、风速和昼夜条件确认。

## 8. 扩散模型的自动选择

### 8.1 空气密度

系统根据环境压力和温度计算空气密度。

### 8.2 Richardson 数

系统结合气体与空气的密度差、特征尺寸、风速和地表粗糙度计算临界 Richardson 判定值。

### 8.3 路由规则

- 初始气体密度不大于空气密度：使用 Pasquill-Gifford 高斯模型。
- 气体比空气重，但 Richardson 数小于 1：使用高斯模型。
- 气体比空气重，且 Richardson 数大于或等于 1：使用 EPA SLAB 重气模型。

每次计算都会记录气体密度、空气密度、摩擦速度、Richardson 数、模型名称和模型版本。

SLAB 平台可执行文件缺失或运行失败时，重气场景会明确失败，不会悄悄回退到高斯模型。

## 9. 高斯扩散计算

### 9.1 连续烟羽

加压气体和持续蒸发源使用地面反射的高斯烟羽模型。中心线浓度主要受以下因素影响：

- 源强 Q：越大则浓度越高。
- 风速 u：在其他条件不变时，越大则稀释越强。
- 水平扩散尺度 σy 和垂直扩散尺度 σz：根据下风距离、稳定度和粗糙度计算。
- 释放高度 H：影响地面浓度。

系统在每个下风距离上求解浓度等于 ERPG 阈值时的横风宽度，形成左右对称的后果多边形。

### 9.2 瞬时烟团

瞬时释放使用高斯烟团模型。总质量随风向移动，同时水平和垂直扩展。逐时显示用来表现烟团从泄漏点到达下风向目标的过程。

## 10. ERPG 后果分区

### 10.1 ERPG-1（蓝色）

表示人员暴露后可能出现轻微、短暂健康影响的外层范围。由于阈值最低，其范围通常最大。

### 10.2 ERPG-2（黄色）

表示人员可能出现明显健康影响，并可能妨碍采取防护行动的中间范围。

### 10.3 ERPG-3（红色）

表示可能出现危及生命健康影响的内层范围。由于阈值最高，其范围通常最小，但优先级最高。

正常结果应满足：

`ERPG-3 ⊆ ERPG-2 ⊆ ERPG-1`

## 11. 结果指标解读

### 最远下风距离

从泄漏点沿下风向到达对应 ERPG 阈值的最远距离。

### 最大宽度

对应影响区在横风方向的最大总宽度。

### 面积

对应后果多边形的平面面积，页面以 ha 显示，1 ha = 10000 m²。

### 峰值浓度

计算浓度场中的最大质量浓度。该值不代表人员在整个暴露期内始终承受该浓度。

### 到达时间

泄漏开始后，对应浓度区域到达该下风位置所需的估算时间。

### 持续时间

该阈值影响可能持续的估计时间。实际现场会受风向摆动、应急切断和建筑物绕流影响。

### 最大包络与逐时羽流

- 最大包络：显示整个计算时段内可能覆盖的最大区域，适合快速划定警戒范围。
- 逐时羽流：显示指定时刻气团所在的范围，适合判断到达顺序和应急撤离时机。

## 12. 风险要素相交与疏散提示

系统将地图上已配置的人员、摄像头、物资、危险源等点位转换为平面坐标，再判断该点是否落入 ERPG 多边形。

风险提醒是确定性的空间相交结果，不是概率风险。

疏散方向优先选择上风向或侧上风向，避免直接穿越羽流。实际疏散还必须结合道路通行状态、现场监测数据和应急指挥命令。

## 13. 计算阻断条件

出现以下情况时，系统不进行正式计算：

- 地图未标定或最大校验误差超过 5 m。
- 分子量或 ERPG 阈值不完整。
- 非内置液化气缺少液体密度、沸点、蒸气压、气液热容、汽化热或绝热指数。
- ERPG 单位不是 ppm，或者阈值不满足 ERPG-1 < ERPG-2 < ERPG-3。
- 风速低于 0.5 m/s。
- Pasquill 稳定度未确认。
- 库存、温度、孔径、压力等必填参数不是有效正值。
- 液相泄漏的设备绝压不高于环境压力。
- 重气场景需要 SLAB，但当前平台的 SLAB 可执行文件缺失或运行失败。

## 14. 计算快照与可重复性

每次计算会在本地 SQLite 中保存：

- 用户原始输入。
- SI 标准化参数。
- 解析后的 SI 物性、物性模式和 ERPG 阈值。
- 气象数据来源和人工修正状态。
- 高斯/SLAB 模型路由与判定值。
- 计算引擎版本。
- 后果分区、逐时结果和错误信息。

相同的输入和引擎版本应生成相同结果。

## 15. 当前模型边界

当前版本只模拟非反应性有毒气体在平坦地形上的快速扩散，不包含：

- 火灾、爆炸和化学反应。
- 复杂山地和明显高程变化。
- 建筑物绕流和街道峡谷效应。
- 室内扩散。
- 沉降、地面吸附和复杂湿化反应。
- 多泄漏源同时叠加。
- 个人风险、社会风险和 F-N 曲线。

## 16. 参考依据

- AQ/T 3046-2013《化工企业定量风险评价导则》：泄漏源项、扩散计算和事故后果阈值处理。
- EPA SLAB：重气的近场与远场扩散计算。
- NIST Chemistry WebBook、NOAA CAMEO Chemicals：四种内置化学品固定参考物性。
- AIHA ERPG：ERPG-1、ERPG-2、ERPG-3 应急暴露阈值。

内置物性和理想气体近似由计算引擎 `1.1.x` 固定；ERPG 数值以接口或人工录入值为准。
